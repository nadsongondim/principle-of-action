# Chapter 11 — Drug-receptor interaction and molecular pharmacology

> This directory contains the runnable examples of Chapter 11 of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the repository root.

## Contents

- `01_kd_to_delta_g.py` — converts dissociation constants `K_d` into binding free energy at 310 K.
- `02_competitive_antagonism.py` — plots the dose-response family for three concentrations of a competitive antagonist.

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_kd_to_delta_g.py
    python 02_competitive_antagonism.py
