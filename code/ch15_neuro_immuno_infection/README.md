# Chapter 15 — Neurophysiology, immunology and infection

> This directory contains the runnable examples for Chapter 15 of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the root of the repository.

## Contents

- `01_fitzhugh_nagumo.py` — FN model with two stimuli (sub- and suprathreshold) and the firing threshold of the action potential.
- `02_bacterial_growth.py` — compares exponential and logistic growth of a bacterial population.
- `03_pkpd_antimicrobials.py` — extracts `T>MIC` and `Cmax/MIC` from repeated IV bolus regimens.

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_fitzhugh_nagumo.py
    python 02_bacterial_growth.py
    python 03_pkpd_antimicrobials.py
