# Chapter 18 — Integrated cases in quantitative medicine

> This directory contains the runnable examples for Chapter 18 of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the root of the repository.

## Contents

- `01_hypertension_windkessel_treatment.py` — Windkessel simulation comparing a hypertensive patient and vasodilator treatment.
- `02_radiotherapy_eqd2_breast.py` — calculates EQD2 of the conventional vs. hypofractionated regimen for breast cancer.
- `03_eqd2_three_regimens.py` — compares three adjuvant radiotherapy regimens (conventional, hypofractionated, ultra-hypofractionated).

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_hypertension_windkessel_treatment.py
    python 02_radiotherapy_eqd2_breast.py
    python 03_eqd2_three_regimens.py
