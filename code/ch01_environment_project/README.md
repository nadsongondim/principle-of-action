# Chapter 1 — Development environment and project organization

> This directory contains the runnable examples of Chapter 1 of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the repository root.

## Contents

- `01_hello_numpy.py` — checks the NumPy installation and shows vectorized use of arrays.
- `02_decay.py` — the smallest reproducible project possible: simulates an exponential decay and saves the figure.

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_hello_numpy.py
    python 02_decay.py
