# Chapter 19 — Prototype of a physiological digital twin

> This directory contains the runnable examples for Chapter 19 of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the root of the repository.

## Contents

- `01_baseline_state.py` — assembles the baseline state of the digital twin from population priors.
- `02_bayesian_update.py` — skeleton of the Bayesian update of PK parameters (placeholders for MCMC/Laplace).

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_baseline_state.py
    python 02_bayesian_update.py
