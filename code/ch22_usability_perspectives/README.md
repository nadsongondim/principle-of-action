# Chapter 22 — Usability, adoption and perspectives

> This directory contains the runnable examples for Chapter 22 of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the root of the repository.

## Contents

- `01_hybrid_pk_model.py` — skeleton of a hybrid PK model: mechanistic (two compartments) coupled to a learned layer (placeholder) that adjusts parameters by covariates.

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_hybrid_pk_model.py
