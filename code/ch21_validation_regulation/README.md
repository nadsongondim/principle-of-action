# Chapter 21 — Validation, regulation and clinical responsibility

> This directory contains the runnable examples for Chapter 21 of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the root of the repository.

## Contents

- `01_model_recalibration.py` — recalibrates the probabilities of an overconfident model using Platt scaling and isotonic regression.

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_model_recalibration.py
