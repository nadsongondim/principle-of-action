# Executable code — Volume 4

This directory contains one subdirectory per chapter of *Volume 4 —
Unified Computational Modeling* of the series **The Principle of Action**.

Each subdirectory provides:

- a `README.md` listing the chapter's examples;
- one or more `.py` files reproducing, in full, the code blocks
  presented in the book.

To run any script, from the root of the repository:

```bash
python code/<directory_name>/<file>.py
```

See the [repository root](../README.md) for the full map of the 22
chapters, installation instructions and citation.
