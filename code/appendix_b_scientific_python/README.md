# Appendix B — Quick Guide to Scientific Python

> This directory contains the runnable examples of Appendix B of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the root of the repository.

## Contents

- `01_numpy_basics.py` — creating arrays, vectorization, indexing and reductions.
- `02_scipy_algorithms.py` — `solve_ivp`, `minimize`, `curve_fit`, `quad`, interpolators.
- `03_sympy_symbolic.py` — derivative, integral, `dsolve` and `lambdify`.
- `04_matplotlib_basics.py` — simple figure and multiple panels.
- `05_pandas_time_series.py` — loading a CSV, filtering and working with time series.
- `06_good_practices.py` — `np.random.default_rng` with a fixed seed.

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_numpy_basics.py
    python 02_scipy_algorithms.py
    python 03_sympy_symbolic.py
    python 04_matplotlib_basics.py
    python 05_pandas_time_series.py
    python 06_good_practices.py
