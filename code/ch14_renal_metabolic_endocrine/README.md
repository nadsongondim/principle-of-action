# Chapter 14 — Renal, metabolic and endocrine systems

> This directory contains the runnable examples of Chapter 14 of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the repository root.

## Contents

- `01_cockcroft_gault.py` — estimates `CrCl` with the historical Cockcroft-Gault formula.
- `02_basic_bergman_model.py` — skeleton of the Bergman minimal model for glucose-insulin dynamics.
- `03_renal_dose_adjustment.py` — proportional adjustment of the aminoglycoside dose for renal function.
- `04_ogtt_normal_diabetic.py` — simulates an OGTT in a normal individual and in a type 2 diabetic.

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_cockcroft_gault.py
    python 02_basic_bergman_model.py
    python 03_renal_dose_adjustment.py
    python 04_ogtt_normal_diabetic.py
