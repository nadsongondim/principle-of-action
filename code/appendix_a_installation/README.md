# Appendix A — Installing and Configuring the Environment

> This directory contains the environment-check script of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the root of the repository.

## Contents

- `check_environment.py` — prints the installed versions and confirms that NumPy, SciPy, SymPy, Matplotlib, pandas and scikit-learn are available.

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python check_environment.py

The output should list the versions and confirm `Environment ready.`.
