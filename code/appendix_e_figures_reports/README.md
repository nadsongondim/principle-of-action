# Appendix E — Good Practices for Figures and Reports

> This directory contains the runnable examples of Appendix E of Volume 4 of the series
> *The Principle of Action*. For the complete book, see the root of the repository.

## Contents

- `01_matplotlib_style.py` — the series palette (NAVY/ACCENT/SOFT/FILL) and standardized `rcParams`.
- `02_save_figure_standard.py` — naming convention and `fig.savefig` parameters for reproducibility.

## How to run

Install the requirements (see `requirements.txt` at the root) and run:

    python 01_matplotlib_style.py
    python 02_save_figure_standard.py
